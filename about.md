I build small web APIs around Japanese data (holidays, era dates, romaji, municipalities, railway stations) and logic puzzles (number place, nonogram, kakuro). They are published on RapidAPI with free plans, and the example code is on GitHub.

Posts here are drafted with help from an AI assistant. All code is run and checked against real data before it is published.
